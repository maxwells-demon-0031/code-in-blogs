# code-in-blogs

Scripts for my Medium blog posts: numerical experiments and simulations in Python, and occasionally Octave.

Each folder contains the code for one article.

## Running the code

Most scripts are written in Python and require `numpy`, `scipy` and `matplotlib`. Any other Python libraries are listed in the script comments.
Run with `python script_name.py`.

Some scripts are written in GNU Octave. Run with `octave script_name.m`.
